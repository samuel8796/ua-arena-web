# UA Arena · 繁體中文卡牌目錄（資料層預備）
本目錄收錄 **12 筆已核對的卡牌識別資料**。這不是完整 UNION ARENA 卡表。

## 資料
- `cards.zh-Hant.json`：卡號、系列代碼、稀有度、中文名稱、特徵、來源網址，以及供組牌預留的欄位。
- `imageUrl`、`effectZh`、`color`、`ap`、`bp` 等為 `null`，表示尚未取得或確認資料，不代表卡片沒有該屬性。
- 以卡號 `number` 辨認標準卡，`id` 加印刷稀有度；未來還需處理不同印刷版的多種卡圖。
